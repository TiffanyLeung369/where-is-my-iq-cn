## 踩过的坑

### 手机缓存问题（重要！）
- `python -m http.server` 不发 Cache-Control 头，安卓 Chrome 激进缓存
- 即使 JS 文件加了 `?v=30` 版本号，如果 index.html 本身被缓存（304），手机根本拿不到新版本号
- **解决方案**：使用 `server.py`（带 no-cache 头）
- **以后每次改代码后**，如果只改了 JS 但没改 index.html 的版本号，手机可能加载旧代码
- **结论**：用 server.py 就不需要操心版本号了

### 手机调试技巧
- 安卓 Chrome 不支持地址栏执行 `javascript:` 命令
- 需要调试时创建临时 `reset.html` 页面，用完即删
