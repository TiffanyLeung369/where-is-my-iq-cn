# 海外版文案翻译对照表（2026-06-29）

> 游戏海外版统一名称：**Where's My IQ**  
> 本表按“海外玩家自然表达”整理，不做生硬直译。  
> 范围：正式 H5 运行时玩家可见文字、配置标题、PWA 信息、需要用户处理的图片内文字。  
> 不包含：代码注释、开发调试页面、备忘录、软著材料、console 日志。

---

## 是否需要中英双语

**结论：不建议在海外正式版界面中做中英双语。**

原因：

1. 海外玩家看到双语 UI 会觉得像未完成的本地化版本，降低产品完成度。
2. 手机 H5 屏幕空间有限，双语会显得拥挤，影响按钮、弹窗和教程可读性。
3. 当前目标是海外发布，正式展示应统一英文。
4. 中文语言包可以保留作为开发对照或未来语言切换基础，但默认展示应为英文。

建议：

- **正式海外版：英文单语。**
- **开发阶段：保留中文包作为对照。**
- **未来如果要做多语言：使用语言切换，而不是同屏双语。**

### 提示系统英文运行规范（已核对）

- 提示理由在海外版运行时必须使用英文语言包；当前 `I18n.currentLang` 固定为 `en`，中文语言包只作为开发对照保留。
- `{colors}` 是动态颜色名称列表，英文界面必须使用英文逗号和自然英文连接方式，例如 `Sky Blue, Orange` 或 `Sky Blue and Orange`；禁止使用中文书名号 `「」`、中文顿号 `、` 或其他中文分隔符。当前代码曾拼出 `「Sky Blue」、「Orange」`，这不是有效的海外版英文显示格式。
- `{skinName}` 必须传入语言包中的正式英文名称，例如 `Crab`、`Piglet`、`Sea Turtle`，不能传入内部 ID 或小写名称，例如 `crab`、`pig`、`turtle`。内部 ID 只用于逻辑，不得直接展示给玩家。
- `hint.row_only_spot`、`hint.col_only_spot`、`hint.region_only_spot` 的实际逻辑支持一次填入 N 个候选格；文案不能在支持多个候选时固定写成单数 `one possible spot`，应根据数量使用 `one spot` / `the only remaining spots` 等与实际数量一致的英文。
- 英文提示中的 `X`、`×` 必须保持与按钮和实际操作一致：标记排除使用 `Mark X`，候选填入使用 `Place It`；不得在同一条英文提示中混入中文标点。
