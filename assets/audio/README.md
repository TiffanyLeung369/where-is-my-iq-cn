## BGM 背景音乐（待添加）

| 文件名 | 用途 | 风格 |
|--------|------|------|
| `bgm_menu.mp3` | 菜单/首页 BGM | 轻快可爱、休闲益智风 |
| `bgm_battle.mp3` | 生存模式 BGM | 紧张刺激、节奏感强 |

> **BGM 获取指南**：
> 1. 前往 https://pixabay.com/music/search/cute%20casual%20puzzle/ 选一首菜单 BGM
> 2. 前往 https://pixabay.com/music/search/battle%20tense%20game/ 选一首战斗 BGM
> 3. 裁剪至 15-30 秒可循环片段，压缩到 ≤ 150KB
> 4. 重命名为 `bgm_menu.mp3` 和 `bgm_battle.mp3` 放入此目录
